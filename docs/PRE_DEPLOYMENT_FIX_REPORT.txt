6. /api/auth/me FINAL CONTRACT
--------------------------------------------------------------------------------

Method:       GET (session probe), DELETE (sign out)
Logged out:   HTTP 200, body { "user": null }
Logged in:    HTTP 200, body { "user": { id, email, ... } } (no secrets in response)
Cache:        Cache-Control: private, no-store (mandatory)
Consumers:    AuthContext treats missing user as signed-out; status 200 preserved
              intentionally to avoid breaking client auth bootstrap.
Rationale:    Not changed to 401 — would break existing AuthContext session probe.
