4. HIGH-PRIORITY ISSUES
--------------------------------------------------------------------------------

H1. Invalid / unknown routes return HTTP 200 instead of 404
    Evidence: Runtime audit (http://127.0.0.1:3010)
      /subjects/not-a-real-subject-xyz          → 200 "Subject not found"
      /subjects/indian-polity/not-a-real-topic  → 200 "Topic not found"
      /totally-unknown-route-404-test           → 200 (catch-all [subject] route)
    Impact: SEO crawlers may index soft-404 pages; monitoring may miss errors.
    Recommendation: Return notFound() (404) or noindex + explicit 404 status.

H2. Authenticated mutation tests BLOCKED (live Supabase)
    Reason: .env.local uses production Supabase credentials; no confirmed
    staging-only test account. Submit/idempotency/progress exclusion not
    runtime-verified in this audit (code review only).

H3. npm audit — production dependencies (3 high)
    Command: npm audit --omit=dev  → exit 1
    Packages: next, postcss, sharp (multiple GHSA/CVE advisories)
    Action: Review advisories; patch on staging before production promotion.
    Did NOT run npm audit fix (per safety rules).

H4. /dashboard and /profile accessible logged-out with static cache
    Evidence: HTTP 200, Cache-Control s-maxage=31536000, no redirect to login.
    Client shows sign-in prompt (DashboardClient) — private data not exposed
    in HTML, but page is publicly cacheable at CDN layer on Vercel Preview.
    Recommendation: force-dynamic + private/no-store or server redirect.
